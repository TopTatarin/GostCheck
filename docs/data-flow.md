# Поток данных извлечения

Команда `normocontrol extract` преобразует локальный `.tex` или `.pdf` в единый
`DocumentBundle`. Извлечение не обращается к сети, не запускает TeX и не выполняет OCR.

```text
LaTeX main ── safe input/include ── AST headings ──┐
                                                   ├─ sections ── chunks ── bundle.json
PDF bytes ── PyMuPDF spans/pages ── outline/font ──┘
```

## LaTeX

`project_root` является границей доверия. Главный файл и каждый относительный
`input`/`include` разрешаются через реальный путь; переход `..` и символьная ссылка за пределы
корня отклоняются. Отсутствующие файлы и циклы include дают типизированную ошибку. Комментарии
удаляются до поиска include, поэтому закомментированная директива не исполняется. `\%` остаётся
текстом, а тела `verbatim`, `Verbatim`, `lstlisting` и `minted` защищаются от обработки директив.

Порядок `source_files` соответствует первому детерминированному обходу от main-файла. В bundle
попадают только относительный POSIX-путь и SHA-256 каждого файла; абсолютные пути не
сериализуются.

Orchestrator отдельно обнаруживает библиографии из незакомментированных
`\addbibresource{...}` и `\bibliography{a,b}` во всех достижимых `input/include`. Если команд
нет, используется детерминированный обход `.bib` внутри `project_root`. Расширение `.bib` можно
опустить; Windows- и POSIX-разделители нормализуются. Пути с `..`, absolute/drive-пути и
symlink/junction наружу отклоняются до чтения. После разрешения дубликаты удаляются по
нормализованному относительному пути, а результат сортируется как POSIX-путь. В диагностику не
попадают абсолютный путь и содержимое библиографии.

## PDF

PyMuPDF сохраняет для каждого span страницу, шрифт, размер и bbox, а для страницы — ширину,
высоту и поворот. Узкие блоки двух колонок читаются сверху вниз сначала в левой, затем в правой
колонке. Outline имеет приоритет перед кандидатами по размеру шрифта; повторяющийся верхний или
нижний колонтитул не становится секцией. Лигатуры `ﬀ/ﬁ/ﬂ/ﬃ/ﬄ` нормализуются.

`extraction_quality` равен `high` при пригодном текстовом слое. Значение `degraded` и код
`PDF_NO_TEXT_LAYER` явно обозначают PDF без текста; `PDF_ZERO_BBOX` обозначает ненадёжную
геометрию. OCR намеренно не запускается. Повреждённый и зашифрованный PDF возвращают разные
типизированные ошибки без включения содержимого документа в диагностику.

После успешного `latexmk` orchestrator повторно извлекает скомпилированный PDF. LaTeX
`DocumentBundle` остаётся основным bundle с AST-секциями, а spans/pages хранятся в отдельном
`ExecutionContext.pdf_bundle`; поэтому `source_format` не смешиваются и FMT/FIG-метрики получают
геометрию PDF без потери LaTeX-структуры. Успешный `latexmk` без PDF и повреждённый PDF дают
безопасный degraded-результат (или fail-closed ошибку). Содержимое `.bib` и compiled PDF входит
в детерминированные cache keys, поэтому изменение любого артефакта инвалидирует build/formal
кэш.

## Секции, chunks и evidence

Секции из LaTeX AST приоритетнее PDF outline и эвристики шрифта. `annotation`, `introduction`,
`conclusion` (включая старое имя «Выводы») и буквенные `appendix-*` имеют стабильные адреса.
Fuzzy-сопоставление заголовка используется только для адресации и не создаёт блокирующий
результат.

`Chunker` режет внутри границ секции, предпочитая абзац, предложение и пробел. Для длинного
слова или таблицы без пробелов применяется точный Unicode-разрез. Консервативная оценка бюджета
основана на длине UTF-8; `token_count` никогда не превышает `--token-budget`. Overlap ограничен
10% бюджета и не пересекает секцию. Уникальная часть каждого chunk начинается с
`content_start`; поэтому исходный нормализованный текст восстанавливается как
`chunk.text[chunk.overlap_chars:]` в порядке chunks.

Каждый chunk содержит SHA-256 нормализованного текста, `section_id`, диапазон страниц и
path-free locator вида `sha256:<hash>:<start>-<end>`. `resolve_quote` принимает только диапазон
внутри опубликованного chunk, проверяет hash и по умолчанию раскрывает не более 400 символов.
Поля с текстом исключены из `repr`, поэтому штатная диагностика не печатает ВКР. Сам
`bundle.json` содержит извлечённый текст и должен оставаться локальным артефактом сборки; его
нельзя коммитить или передавать облачному провайдеру при `allow_cloud_data: false`.

Пример:

```powershell
normocontrol extract tests/fixtures/extract/minimal/main.tex --out build/bundle.json
```
